The verified environment is Python 3.11.16 on macOS 26.3 arm64 with Apple M1 Pro, 16 GiB unified memory and MPS. Linux and other platforms have not been measured; CPU inference is supported by the entry points.

Create an isolated environment with Python 3.11.16, then install the exact compute-box package snapshot:

python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements-lock.txt

Installation needs access to Python package indexes and the pinned HatchFinder Git repository. Inference uses supplied local model files and original drawing assets; it does not download training data or weights. Dataset release and weight hashes are recorded separately.

Verification:
RUN_IMAGE_TESTS=1 .venv/bin/python -m pytest -q
.venv/bin/python -m ruff check .

The challenge code is MIT. The external HatchFinder code and declared weight license are Apache 2.0; third_party/hatchfinder-LICENSE preserves the pinned code license. Dataset use follows DATA_TERMS.md. The pretrained training-image list is unavailable, so overlap with challenge drawings cannot be certified.
