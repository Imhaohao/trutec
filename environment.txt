Submitted system (v14) environment

Measured on Python 3.11.16, macOS 26.3 arm64, Apple M1 Pro with 16 GiB unified memory (validation run), and on Python 3.11 / macOS arm64 with Apple M5 Pro (reproduction run). v14 uses CPU tree models only; no GPU, MPS or network access is used during inference. Linux and other platforms have not been measured.

Install:

python3.11 -m venv .venv
.venv/bin/python -m pip install -r requirements-inference.txt

requirements-inference.txt pins numpy 2.4.6, Pillow 11.3.0, opencv-python-headless 5.0.0.93, scipy 1.17.1, scikit-learn 1.9.1 and joblib 1.6.0. No system libraries beyond those wheels are required.

Model files: download https://github.com/Imhaohao/trutec/releases/download/v14/models-v14.zip (byte length and SHA-256 in submission.json and artifacts/delivery-v14/checksums.txt) and unzip it into models/v14/. It holds stage1-alldata-v12.joblib, stage2-structure-hgb-v14.joblib and their JSON records.

Inference:

.venv/bin/python infer_v14.py --inputs <label-free requests.json> --data-root <drawing root> --output-dir <output dir>

Verification:

.venv/bin/python -m pytest -q tests/test_infer_v14.py
.venv/bin/python evaluate.py --manifest dataset/val.json --data-root dataset --predictions <output dir> --output metrics.json

The full research environment (earlier HatchFinder/DINO experiments) is pinned in requirements-lock.txt and needs the pinned HatchFinder Git repository; it is not needed for v14.

Licenses: the challenge code is MIT. Dataset use follows DATA_TERMS.md. The HatchFinder code and declared weight license (Apache 2.0, third_party/hatchfinder-LICENSE) apply only to the earlier research pipelines, not to v14.

Report figures for v14 (artifacts/report-v14) are rendered with Pillow only:

.venv/bin/python tools/render_overlays.py --manifest dataset/val.json --data-root dataset --predictions <output dir> --output-dir artifacts/report-v14 --ids q-dd48fe13cfa62e19 q-752be75351e18024 q-61012bd70ddb4b3b
