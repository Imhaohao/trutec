Task and contract

For each original construction drawing and rectangular hatch example, inference writes one binary PNG at the original image dimensions. Optional context rectangles remain inputs. Annotation files, rectangles, expected counts and private labels are excluded from inference. Query and context rectangles are excluded by the official evaluator. Unknown pixels are unscored and are never treated as training negatives.

Method

The texture model compares local pattern descriptors with the supplied query descriptor. A histogram gradient-boosting classifier produces match probabilities. The reference-conditioned HatchFinder CNN independently predicts a match probability at native resolution using overlapping 896-pixel tiles. Their accepted pixels are intersected. A label-free query-self probability statistic sets the texture threshold; every query uses the same frozen formula and CNN threshold.

The MPS compatibility bridge executes only nondivisible adaptive query pooling on CPU. It preserves native query dimensions and pooling values/gradients. It does not resize query crops to satisfy the accelerator. Model input search masks are all ones; reviewed annotations are used only for fitting and scoring.

Training and failed approaches

HGB fitting uses up to 512 reviewed positives and 512 reviewed negatives per query, per-query normalized weights, stride 4, 200 boosting iterations, learning rate 0.08, 31 leaves, L2 1.0 and seed 42. Crop-only query statistics did not improve peak standalone IoU. Removing generated CAD fitting examples worsened measured generalization, so the mixed fitting data remains eligible.

The first CNN adaptation trained 200 head-only native 896-pixel updates from the pinned pretrained model with frozen encoders, AdamW lr=1e-4 and reviewed masked BCE+Dice. The continuation adds 800 updates with seed 43, a restarted optimizer and alternating positive/negative coverage epochs. Training duration and sampling both change, so any accuracy change cannot be attributed to sampling alone. Coverage must be checked from actual provenance, rather than inferred from training duration.

The completed continuation's actual ordered provenance confirms 400 positive and 400 negative draws, covering all 357 positive-eligible and 330 negative-eligible fitting queries without first-epoch repeats. It completed in 1492.97 external wall seconds. Its recall-gated fusion did not outperform the earlier 200-update model, so longer training alone does not justify selecting it. Final weights hash: 48412c6ef321bd033409909030d1dfca270a8b7b4341e52f1bda7369e50c839a.

The optional 8x8 native-luminance variance feature failed its predeclared acceptance checks. At fixed threshold 0.6, macro IoU was 0.6546174368647742 versus 0.6624318182678043 for base features, and recall was 0.752503974562798 versus 0.7562599364069952. In doc-7d2e7245f04790b8, false positives increased from 159,751 to 172,031; in doc-cfd973b494d531ad they decreased from 206,506 to 183,255. The frozen system retains the base features. Legacy feature values are independently verified unchanged, and optional feature reports remain diagnostic only.

Failure cases and metric limits

Development errors concentrate on competing diagonal linework, faint textures and contaminated query crops containing callouts or arrows. These observations motivate experiments but do not prove causation. Precision and false-positive counts must accompany recall. Document-macro IoU first averages eligible query IoUs within each document, then averages documents; pooled recall weights positive pixels. Their denominators differ. Positive-only examples cannot demonstrate discrimination against negatives. Reviewed-blank false-positive rate is null in development because no eligible explicit blank pixels were observed. Null does not mean zero false positives. Unreviewed sheet accuracy remains unknown.
