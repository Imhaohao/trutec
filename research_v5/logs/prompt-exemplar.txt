Read research_v5/BRIEF.txt and research_v5/devharness.py first and obey every rule in the brief. Your directory is research_v5/exemplar/ ; create files only there.

Goal: build and measure a label-free TEST-TIME EXEMPLAR matcher. For each query, train a small classifier at inference time using only that drawing: positives are descriptor cells inside the query box (with small shift augmentation), and the unlabeled pool is cells sampled from the rest of the same drawing (positive-unlabeled learning: the query pattern usually covers a small fraction of the sheet, so unlabeled cells are mostly negative). Score every cell of the drawing, then map scores to the reviewed coordinates (y, x) with the same function a full-image mask would use (nearest or bilinear grid lookup) so the score at a pixel does not depend on which pixels are scored.

Descriptors: build a rich multi-scale local descriptor at a fixed grid stride (start with 8 px) from the RGB drawing: per-window ink density at several windows (8/16/32/64 px) for luminance and for chroma, gradient-orientation histograms, structure-tensor coherence/orientation, local FFT magnitude in orientation x radial-frequency bins (period of hatch lines), and optionally hatch_texture.texture_features. Use box filters / integral images so a 7200x4800 sheet runs in under about 30 s per query. Positives come from cells whose full window lies inside the query box when the box is large enough; handle small boxes by using the smallest windows.

Classifier: start with standardized features plus logistic regression or a linear SVM with class weights (positives vs unlabeled), then try a nearest-prototype score (Mahalanobis / k-NN distance to query cells versus distance to unlabeled cells). Calibrate each query's scores to [0,1] without labels (for example a rank-based or sigmoid mapping anchored on the query cells' own score distribution).

Measure with devharness.report or run_predictor on all 55 development queries; save every result JSON in research_v5/exemplar/. Also measure a fusion with the existing HGB cache (devharness.cached_scores(devharness.HGB_CACHE)), e.g. geometric mean or min, because the exemplar score may supply discrimination while HGB supplies recall. Iterate on whatever the development numbers say for up to about 3 hours, but keep a log in research_v5/exemplar/findings.txt listing each variant, its exact settings, and the best macro IoU and best precision at recall >= 0.98 from the harness. Run .venv/bin/ruff check research_v5/exemplar at the end. Finish with a concise plain-text summary of what worked, what failed, and the single best variant with its numbers.
